# Lilagan Café

A simple Flask web application created for EGN475.

## Project Description
Lilagan Café is a prototype web application for a neighborhood coffee shop.

## Technologies
- Python 3.14
- Flask 3.1
- Git and GitHub
- GitHub Copilot

## Features
- Home page with a welcome message
- About page with a business description

## Running the Application
1. Activate the Python virtual environment.
2. Install dependencies using `python -m pip install -r requirements.txt`.
3. Run `python -m flask --app app run --debug`.
4. Visit http://127.0.0.1:5000.
